# Documentation-source instructions

- `geographic_code_contract.md` is an active persistent-schema contract and must agree with R and Python normalizers.
- `raw_data_sources.yaml` is the machine-readable source catalog. Keep it valid YAML with stable unique IDs, coverage, provider, access method/URL, credentials where relevant, and caveats.
- Word documents are dated historical design notes. Preserve them as archival records; do not update them to masquerade as the current implementation. Put current agent guidance in Zola and current manuscript claims in the draft.
- When code supersedes a historical proposal, add an explicit status note to the agent guide so text-first agents do not revive it.
