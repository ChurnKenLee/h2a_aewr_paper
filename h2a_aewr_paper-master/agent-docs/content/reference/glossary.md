- **AEWR:** Adverse Effect Wage Rate; the project uses multiple transformations and comparisons, so name the exact variable.
- **Artifact owner:** the single script/stage responsible for producing a persistent file.
- **Compatibility code:** retained executable implementation used for benchmark/migration, not the supported default.
- **Design-neutral:** reusable construction that does not encode a treatment, instrument, design sample, or inference rule.
- **Dry run:** runner ordering without language imports, data reads, network, or computation.
- **FLS:** Farm Labor Survey.
- **Generated grounding:** deterministic Zola pages and manifests derived from current repository inputs.
- **Historical:** preserved provenance that must not be read as current implementation guidance.
- **Static propensity:** the cutoff-specific one-row-per-county H-2A PPML score repeated across panel years; not a rolling annual score.
- **Support:** observed treatment/dose coverage relevant to a reported contrast; not interchangeable with sample size.
