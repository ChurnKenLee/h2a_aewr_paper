# Retained-output instructions

- These are generated manuscript products with owning scripts. Do not repair
  values, labels, notes, or formatting directly.
- Before replacing an output, record input versions, runner, environment locks,
  model or specification identifiers, and validation evidence.
- Preserve diagnostic, null, and negative results. Do not delete outputs merely
  because they complicate the preferred interpretation.
- Large or transient products belong in ignored paths; commit only intentionally
  retained outputs.
