================================================================================
  ANALYSIS WORKFLOW: Farm Labor Scarcity and Its Uneven Impacts on U.S. Crop Producers
  Ray, Haqiqi, Hill, Taylor, and Hertel
  INSTRUCTIONS FOR REPLICATION
================================================================================

To execute the replication you need:

Software:
GEMPACK (Horridge et al. 2025)       -- free six-month trial license available
                                     from Centre of Policy Studies, Monash University
				     here: https://www.copsmodels.com/gpeidl.htm
R (required) or RStudio (optional)   -- free 
				     https://cran.r-project.org/
				     https://posit.co/download/rstudio-desktop/

Steps:
1. Download the replication files in Ray26AJAE_Replication from: 10.5281/zenodo.21433723
2. Extract Ray26AJAE_Replication_180726 on your hard drive, note PATH where you save it
3. Install GEMPACK and RStudio
[Otherwise, SIMPLE-G simulation results included in archive/out, paste in out/]
4. Open scripts/0_SetPath_Packages.R and update project_root to PATH from Step2
5. save & close 0_SetPath_Packages.R
6. Run run_replication.bat
   OR
   Run 0a_XXX.R, 1_XXX.R, 2_XXX.R using RStudio
7. Find Figures and Table in manuscript in /figures /tables


================================================================================
  FILES AND FOLDERS: Ray26AJAE_Replication
================================================================================

Top-level structure (after extracting the .zip):

  Ray26AJAE_Replication/
    archives/	      GEMPACK output files archived, 
    in/                Raw/input data (crosswalks, Census, survey, GIS, GEMPACK
                        database files) -- provided, do not need to be created
    plots/             Output figures (.png) -- generated by 1_FIRST_STEP.R and
                        2_SECOND_STEP.R
    out/               GEMPACK solution files (.sl4) -- generated by 2_SECOND_STEP.R
			archival version included in archives/out
    ReadMe/	       Includes readme.txt with replication instructions
       			        Workflow.txt
				Files.txt
    scripts/          R scripts (run these)
    shf/               GEMPACK shock files -- generated by 2_SECOND_STEP.R
    ssa/               mean and variation for SSA
    temp/              R intermediate outputs (.xlsx/.RDS) -- generated by 0a/1/2
    
    *.cmf              GEMPACK control files (e.g. 2-Validation-NAWS-NM3.cmf) --
                        provided, read by simplez.exe
    simplez.exe        GEMPACK executable -- provided / installed with GEMPACK
    run_replication.bat        Windows batch file that runs 0, 0a, 1, and 2 in sequence
